# Security Policy

## Reporting a Vulnerability

**Do not open a public issue.**

Use GitHub's [private vulnerability reporting](../../security/advisories/new)
to report security issues. You'll receive a response within 72 hours.

## Scope

In scope: rate limiting bypass, Admin API auth flaws, injection via
client IDs, Kafka deserialization vulnerabilities, information disclosure.

## Supported Versions

| Version | Supported |
|---------|-----------|
| latest  | Yes       |
