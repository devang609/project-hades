# Project Hades

Self-hosted distributed API gateway with adaptive rate limiting, behavioral anomaly detection, and real-time observability.

## Overview

Project Hades is a production-grade API gateway built on Spring Boot 4.1 WebFlux that goes beyond simple request counting. It implements cost-weighted rate limiting, behavioral fingerprinting via probabilistic data structures, and a learning mode that auto-generates policies from observed traffic patterns.
